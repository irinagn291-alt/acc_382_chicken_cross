Chicken Cross is a native SwiftUI arcade game for iPhone and iPad running iOS 18.2 or later. A fresh launch opens Play, where you can start a free run or the daily route.

Start a free run and hop forwards once to collect a coin. Try the swipe and direction controls, then pause and finish the run. Check the saved result in Records, open Flock to view the six cosmetic hen colours and open Daily to replay today’s route or choose a landscape for a free run. Switching tabs or leaving the active app pauses a run. An unfinished run is ended and saved at local midnight.

Use the system share sheet in Records to share a scorecard, then paste a card into Records to test import. The app verifies signatures on current-format cards. Scores come from the sender, and older cards appear separately as unverified. Confirming the reset in Settings erases main progress and cancels reminders. Imported cards and the signing identity are stored separately and retained.

Enable reminders in Settings to trigger the optional local notification prompt. If allowed, reminders repeat at 09:00 and 18:00 local time. If denied, the link to system settings is behind an arithmetic prompt. Home Screen and Lock Screen widgets read the shared local save and link to Play or Daily. The app also supports a Flock deep link. The build declares a remote notification background mode and a development push entitlement. The app does not register for or handle remote notifications. There is no working Game Center integration or backend, and the app requests no camera, microphone, location or Health access.
